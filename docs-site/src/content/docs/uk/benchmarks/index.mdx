Це **статичні знімки** публічних лідербордів, що оновлюються вручну, — а не живі
дані обліку OpenCodex. Для кожної таблиці зазначено джерело, дату знімка та
примітку про ліцензію. Рейтинги «бали на долар» показуються лише в таблицях, де
кожен рядок містить виміряну джерелом вартість за задачу.

Таблиці згруповано за доменами задач:

- [Кодинг](./coding/) — DeepSWE, AA Coding Agent, FrontierCode, FrontierSWE, Program Bench, SWE Marathon
- [Фронтенд](./frontend/) — Frontend Code Arena
- [Термінал](./terminal/) — Terminal Bench 2.1
- [Безпека](./security/) — Cybench
- [Інтелект](./intelligence/) — AA Intelligence Index
